# Mobile App and API Security

A hands-on security engineering project exploring mobile application
risks, API protection, defensive controls and practical validation.

## Objectives

- Review mobile application permissions and least privilege.
- Demonstrate API authentication and authorisation.
- Examine secure token handling and local data storage.
- Configure and validate HTTPS/TLS.
- Test defensive controls using fictional users and data.
- Document baseline and secured results.

## Technology Stack

- Node.js
- Express
- SQLite
- Visual Studio Code
- Wireshark

## Project Status

Initial setup.

## Scope and Safety

All experiments are intended for educational and defensive security
testing using the project's own application, local environment and
fictional test data.

No unauthorised testing of third-party systems is intended.

## Limitations

This project is a local demonstration. It is not a production-ready
security product and does not, by itself, validate native Android
or iOS security behaviour.
